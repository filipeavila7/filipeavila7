## 🚀 Projetos em destaque

### [Rede Social — API REST](https://github.com/filipeavila7/rede-social-java)
API REST completa de rede social desenvolvida com Java e Spring Boot. Autenticação Bearer JWT com controle de acesso por roles via Spring Security. Endpoints para posts, comentários, curtidas, seguir usuários, mensagens em tempo real e edição de perfil. Frontend em React consumindo todos os endpoints.

`Java` `Spring Boot` `Spring Security` `JWT` `JPA/Hibernate` `MySQL` `React`

---

### [ChatBot AI — Assistente Conversacional](https://github.com/filipeavila7/chatbot)
Aplicação full stack integrando as APIs do Gemini e ChatGPT. Backend em Flask com SQLAlchemy e MySQL para persistência de conversas. Autenticação de usuários com gerenciamento de chats (criação, exclusão e renomeação).

`Python` `Flask` `SQLAlchemy` `MySQL` `Gemini API` `ChatGPT API`
